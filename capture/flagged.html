C-02The schedule is the repository's choice, not a published NFL rule
The cadence (Wed–Fri, daily) was set by this capture. No NFL-published injury-report policy page was opened in this session that states the cadence. The NFL's page is titled 'Official Latest NFL Injury Report … Week 10' and lists games by day. It does not state a release schedule, so the schedule was not taken from it.

C-03Runner egress to nfl.com and club sites is unverified
The sandbox that wrote this capture cannot reach nfl.com (HTTP 000 from curl). The first real capture happens on a GitHub runner. If a publisher blocks runners, the job fails loudly; it is not replaced by a copy.

On 2026-11-15 (UTC) the NFL page is titled 'Injuries - WEEK 10' and lists games dated Thursday 12 November and Sunday 15 November 2026. No Week 11 page was visible in this session. Captures will show this as 'unchanged' or 'changed' bytes, not as a week change, until the page moves.

C-05Club pages are not all the same shape
Club depth pages carry different markers and table structures (see depth_lab flags F01–F10, for example Houston renders its tables with browser script). The capture records the marker and the table counts; a page that loads a shell without tables will show a table count of 0 without a failure, because the required marker is text only.
