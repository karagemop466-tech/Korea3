Provenance note

nflverse is an independent open-source project that distributes NFL data. It is not an NFL-operated service, so this project calls the data "official-derived" rather than "official". The nflverse schedule dataset's own data dictionary attributes the closing spread to Pro Football Reference; the vendor behind the price columns published alongside it is not documented anywhere in the repository, which is recorded as an irregularity.
