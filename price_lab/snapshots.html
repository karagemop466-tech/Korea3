Price-snapshot store

Opening and closing numbers for every market this repository originates, with the model's fair line alongside. Built from the pinned dataset; values no source provides are blanks.

What this store is

One row per originated market per snapshot: open (the earliest recorded market number), close (the final recorded market number) and fair (this repository's own line for the same market). Every row names its book/tier and links the file it came from. Nothing is inferred: a snapshot that no source provides is a blank.
