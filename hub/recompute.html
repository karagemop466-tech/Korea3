Why this page exists

A number is not evidence because a pipeline printed it. Each published figure is re-derived here from the committed CSV with independent arithmetic, and the method is printed next to it so it can be checked again. The honest limit is stated on every row: a value can be reproducible without being official, because the market data behind it is third-party.

Run it yourself: python3 hub/verify_numbers.py. The build fails if any check stops matching.

The checks

Official = fixed by a price or a rule; Recomputed = re-derived from the repository's data; Limitation = a negative result confirming a gap.
