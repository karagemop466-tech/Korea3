How to read this page

This page answers three questions: (1) What information do we need to make a decision? (2) What do we already have? (3) How do we get what we're missing? The gaps table lists everything we don't have. The known-facts table lists everything we do have. The discovery-actions table lists concrete steps to close each gap.

A gap is not a failure. It is an honest statement of what is missing. Decisions made without addressing critical gaps are decisions made on incomplete information.

Information gaps — what we don't know

Each gap is classified Critical / High / Medium / Low. Critical gaps block all verified betting decisions. High gaps block specific strategy categories. Medium and Low gaps reduce precision but do not invalidate findings.

Every row links to the official source that defines the missing data or the repository file where the gap was identified.
ID Severity Missing information Why it matters Consequence if ignored How to fill the gap Official source
G01 Critical Historical closing-line prices from a licensed operator No official operator publishes a free historical price archive. All prices in this repository come from the nflverse third-party dataset, which is not an official source. Without licensed prices, no strategy ROI can be officially verified. Obtain a data-use agreement with DraftKings, FanDuel, or another licensed operator. Alternative: subscribe to a licensed data vendor (e.g. Sportradar, Genius Sports). DK-SPREAD ↗ FD-CT-RULES ↗
G02 Critical Player-level game logs with prop settlement prices NFL.com publishes box-score stats, but not the per-game prop lines or settlement prices that a player-prop strategy requires. DraftKings defines prop rules (KB0010778) but does not publish historical prop prices. No player-prop strategy can be tested without historical prop lines and player outcomes. Obtain licensed player-prop price history from a sportsbook or data vendor. NFL.com player stats can partially fill outcome data. DK-PROP ↗ DK-PLAYER ↗
G03 Critical Official NFL injury report machine-readable feed The NFL publishes injury reports as PDFs and web pages each Wednesday, Thursday and Friday. There is no official API or structured data feed. The NFL Support page (NFL-STATS) directs to NFL.com player stats. Without automated injury ingestion, the injury-tracker page remains a framework, not a live tool. Build a scraper for NFL.com injury report pages, or obtain a licensed injury data feed from a vendor. NFL-STATS ↗ NFL-GAMEDAY ↗
G04 High Depth-chart data (starter vs. backup status) Knowing that a team's starting left tackle is out is not enough; the model needs to know who replaces him and what the quality drop-off is. No official source publishes a machine-readable depth chart. Line adjustments for injuries require knowing the replacement player's quality, not just the starter's absence. Use a licensed depth-chart data provider (e.g. FantasyLabs, Rotoworld under NBC Sports) or build a manual depth-chart tracker. NFL-STATS ↗ NFL-GAMEDAY ↗
G05 High Settled bet data (win/loss/push at the actual price taken) To measure whether a strategy is profitable, we need to know the exact price at which each bet was placed and whether it won, lost, or pushed. The nflverse dataset records closing lines, not the prices a bettor actually received. The gap between the model line and the closing line (CLV) is measurable, but actual P&L at the bettor's price is not. Track bets placed at actual prices. Compare to closing lines. This requires a personal bet-tracking system or a licensed operator's account-level data. DK-ODDS ↗ DK-SPREAD ↗
G06 High Same-game parlay (SGP) price schedules DraftKings (DK-SGP) states SGP odds are calculated differently from independent parlay odds, but does not publish the pricing algorithm or a historical SGP price archive. Cannot test whether SGP correlations create a genuine edge without knowing the exact odds offered. Scrape SGP odds from DraftKings or FanDuel over multiple weeks. Build a pricing model. Compare to independent-leg fair value. DK-SGP ↗ FD-CT-RULES ↗
G07 Medium Referee crew assignments (historical) NFL Football Operations publishes weekly referee assignments, but a complete historical archive with crew-level tendencies is not available in a single source. S7 (Referee crew total tendency) needs historical crew data to test properly. Build an archive from operations.nfl.com weekly releases. Compute per-crew scoring tendencies. NFL-GAMEDAY ↗ NFL-SCHEDULE ↗
G08 Medium Weather data at kickoff time (not forecast) S6 (Weather under) uses weather forecasts at the time the line is set. To verify retrospectively, we need the actual weather at kickoff, not the forecast. Using forecast weather introduces look-ahead bias if the forecast changed after the line was set. Obtain historical actual weather data from NOAA/NWS for each stadium at kickoff time. Cross-reference with game times. NIST-MULTI ↗ repo ↗
G09 Medium Defensive scheme classification ( Cover 0/1/2/3/4, blitz rate) Defensive performance varies by scheme. A defense missing its starting CB1 is very different in Cover 2 vs. Cover 0. No official source classifies plays by coverage. Injury impact on defense depends on the scheme the defense runs. Without scheme data, injury adjustments are imprecise. Use Next Gen Stats (nextgenstats.nfl.com) if available, or a licensed play-by-play data provider. NFL-STATS ↗ NFL-GAMEDAY ↗
G10 Medium Offensive line unit cohesion metrics An offensive line with 3 starters and 2 backups performs differently than one with 4 starters and 1 backup, even if the total number of backups is the same. No official metric captures line cohesion. Injury impact on offense depends on which positions are affected and how many linemates the backup has played with. Build a cohesion metric from play-by-play data: track which 5-man line combinations appear together and their performance. NFL-STATS ↗ repo ↗
G11 Low Public betting percentage data Some operators publish the percentage of bets (not money) on each side. This reveals where the public is, which can indicate reverse-line-movement opportunities. Without public bet data, cannot test whether contrarian strategies have an edge. Record public bet percentages from DraftKings or FanDuel over multiple weeks. Compare to line movement. DK-ODDS ↗ FD-CT-RULES ↗
G12 Low Sharp money indicators (steam moves, reverse line movement) Identifying when sharp money enters the market requires monitoring multiple sportsbooks simultaneously and detecting coordinated line moves. Without sharp money indicators, cannot test market-efficiency hypotheses or sharp-following strategies. Subscribe to a line-monitoring service or build one from multiple operator feeds. DK-ODDS ↗ repo ↗

Known facts — what we do know

These facts are either verified from official sources or reproducible from the committed code and data. They form the foundation on which decisions can be made once the gaps above are filled.

Every row links to the official publisher or repository file that supports it.

K01 Game results (1999-2026) nflverse games.csv — 7,548 games, 7,075 completed regular-season games All scores, dates, locations, and basic metadata are available and verified. repo ↗ NFLVERSE ↗
K02 Historical closing lines (2006-2025) nflverse closing_lines.csv — 20,490 rows with spread, total, and moneyline Third-party dataset; not from a licensed operator. Adequate for backtesting but cannot be officially verified. repo ↗ repo ↗

K04 Correlation structure (measured) Same-game: ML vs spread phi=0.671, spread vs total phi=0.016, ML vs total phi=0.000. Cross-game: phi=0.006. Computed from the nflverse dataset. Not from an official source, but reproducible from committed code. repo ↗ NIST-CORR ↗
K05 Validation gate framework 9 gates: sample size, causality, statistical significance, holdout, permutation, economic significance, practical significance, calibration, multiplicity. Framework is pre-registered and the gates are defined in code. No strategy passed all 9. repo ↗ NIST-MULTI ↗
K06 Luck band quantified Best-of-11 random strategies average +5.4% ROI; 95th percentile +16.3%. A profitable 'winner' appears 93% of the time by luck alone. Any strategy ranking must clear this band to claim skill. Bootstrap methodology per NIST guidance. repo ↗ NIST-BOOT ↗ NIST-CI ↗
K07 The vig (hold) is ~2.75% Average two-way hold in recorded prices is 2.75%. Detecting a 3% per-bet edge at 80% power needs ~6,200 settled bets (~8 seasons). This is the wall every strategy must overcome. Derived from the nflverse closing lines. repo ↗ DK-ODDS ↗
K08 2025 official standings (32 teams) All 32 club rows on nfl.com/standings/division/2025/REG match the repository's independently derived aggregates. Verified row-by-row against the official NFL standings page. NFL-STANDINGS-2025 ↗ repo ↗
K09 Model-implied lines for Week 16-18 (2026) 164 unplayed games have model-generated spreads, totals, and win probabilities. Model output is reproducible. No market prices are available for these games yet. repo ↗ NFL-SCHEDULE ↗
K10 Strategy results (11 strategies, 0 eligible) Best full-sample ROI: S6 Weather under +0.58% (CI includes zero). No strategy passed all 9 gates. Each strategy has 20 seasons of backtest data, 3-season holdout, and permutation testing. repo ↗ repo ↗

Discovery actions — how to fill the gaps

Each discovery action is a concrete, actionable step. These are ordered by which gap they close and by feasibility.

Each action links to the official source that would provide the data or the repository file that needs it.
ID Action Steps Closes gap Source links Official source
D01 Licensed operator price archive Contact DraftKings or FanDuel partnerships. Alternatively, subscribe to Sportradar, Genius Sports, or Sportradar's Betradar. Critical — closes G01 and enables full strategy verification. DK-ODDS ↗ FD-CT-RULES ↗
D02 NFL injury report automation Build a weekly scraper for nfl.com injury report pages (Wed/Thu/Fri releases). Store in data/raw/injuries/. High — enables the injury-tracker page and injury-adjusted line models. NFL-STATS ↗ NFL-GAMEDAY ↗
D03 Depth chart data provider evaluation Evaluate FantasyLabs, Rotoworld/NBC Sports, Sleeper for depth-chart APIs. Compare cost, coverage, and update frequency. High — closes G04, enables backup-quality adjustments. NFL-STATS ↗ repo ↗
D04 NOAA historical weather at NFL stadiums Use NOAA GHCN or ISD station data for each NFL stadium. Match to game dates and kickoff times. Medium — improves S6 weather model accuracy by removing forecast bias. NIST-MULTI ↗ repo ↗
D05 Multi-book line monitoring Set up scraping or API access to 3-5 sportsbooks. Record opening and closing lines. Detect steam moves and reverse line movement. Medium — enables sharp money tracking (G12) and CLV measurement. DK-ODDS ↗ repo ↗
D06 Referee assignment archive builder Scrape operations.nfl.com weekly referee announcements. Build a crew-level database of tendencies (penalty rate, total tendency, etc.). Medium — enables S7 refinement and referee-based overlays. NFL-GAMEDAY ↗ NFL-SCHEDULE ↗
D07 Play-by-play coverage data Evaluate Next Gen Stats access, or PFF/Sportradar play-by-play data for coverage classification. Medium — closes G09, enables scheme-aware injury adjustments. NFL-STATS ↗ repo ↗
