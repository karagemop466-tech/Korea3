Leaderboard competition

The competition is designed so luck is not what gets ranked: a luck-adjusted score, a hard gate set and a multiplicity penalty that grows with the number of strategies tested. No rank, score, ROI or reward is published because none is verified.

Anti-gaming rules

Pre-registration, no dropping losers, declared snapshot cadence, price honesty, no post-hoc trimming and a full audit trail.

Rule Why Official source
Pre-registration before the evaluation window Family size feeds the multiplicity penalty, so adding rules after the fact taxes everyone NIST-MULTI ↗
Every tested rule is published Prevents survivorship bias in the displayed board REPO ↗
Only recorded executable prices count Beating the close with an unobtainable price is not skill DK-MARKETS ↗
