Verification log

How every value on this dashboard was checked, and the exact rule used when it could not be checked. No value is inferred, imputed or copied from memory.

Verification convention

Three rules govern every table.

Rule Detail Official basis Official source
Official publisher A domain fact is verified only on the page of the organisation that publishes it. For project-state facts the official publisher is this repository's GitHub tree. NFL Terms; this repository NFL-TERMS ↗ REPO ↗
Blank + flag If a value cannot be confirmed from an official source, the cell renders an em dash plus an 'unverified' link to the review page. It is never filled in. Build gate in this repository repo ↗
Build gate check_hub.py fails on any table row without an official link, any blank without a flag link, any broken internal link, or a source URL outside the official allow-list. check_hub.py repo ↗
