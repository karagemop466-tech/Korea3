Own line origination

The project originates its own spread and total without market input. The fixtures and the method are listed here; every model output and market line is blank because no official executable quote archive exists.

Origination method

The pipeline is described in the repository; the official sources support the market conventions it must respect, not the model's accuracy.

Step What the code does Official basis Official source
1 · Snapshot Pin the input dataset by commit and checksum; exclude unplayed games from all calculations. Repository pipeline repo ↗
2 · Walk-forward Fit team ratings on an expanding window; forecast the spread and total before kickoff. Repository model repo ↗
3 · Sign convention Convert to conventional home spread; verify against outcomes and a second line source. DraftKings point-spread convention repo ↗ DK-SPREAD ↗
4 · Price Compare against the standard −110 quote and push rules used by licensed operators. NFL Support −110; DraftKings Market Rules repo ↗ NFL-ML-ART ↗ DK-MARKETS ↗
5 · Publish Emit own lines for unplayed fixtures; publish only rows that carry an official source. Repository publisher repo ↗
