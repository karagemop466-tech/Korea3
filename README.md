# NFL Research Lab

A static, evidence-first research dashboard for NFL line origination. It documents proposed strategy hypotheses, validation gates, correlation methods, and unresolved gaps. **No strategies have passed validation, no picks are published, and no historical odds or correlations have been verified.** Gambling involves risk; no approach removes luck.

## Local build and checks

Requires Python 3; no dependencies. Run `python3 scripts/build.py` followed by `python3 scripts/check.py`. Open `index.html` or serve the repository root with a static server. Pages is configured to publish the root of `main`.

Each table row links to a primary source supporting relevant facts or methodological context; proposed designs are explicitly labeled as such. Sources are not endorsements of the proposed strategies. The flagged page records missing data and unverified values.
