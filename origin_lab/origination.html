Origination order

Requirement 3 — side, then total, then moneyline, with the dependency that makes it an order.

Why the order is an order. The side is a location forecast and depends on nothing. The total is a forecast of the sum, and once both are fixed the two team scores are pinned by home = (total + margin) / 2 and away = (total - margin) / 2 — so the side has to exist before the total can be turned into team numbers. The moneyline is a tail probability of the margin distribution and needs both the centre from the side and the scale, which the scoring environment sets. It cannot be originated before either.

Causality: the leak probe

Gate P02 asserts that no feature is knowable only after kickoff. An assertion is not a test, so the model is refitted on the same window with the game's own margin added as a regressor. If the probe did not drive R² to 1.0 it would not detect leakage, and the gate would be worthless.
