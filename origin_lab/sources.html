Sources

Every publisher this site quotes, and what each one is allowed to be evidence for.

The line that matters. The NFL publishes rules, schedules, results, standings and player availability. It does not publish point spreads, totals, moneylines or player-prop prices, and neither does any club. Every price on this site comes from a third-party file and says so. Every score comes from the league, or from a file that is reconciled against the league's own page.

Tier is a statement about who published a thing, not about how much this project trusts it.

How a row earns its tier

TierTestSource
officialThe row links a page published by the league, its Football Operations division, or a club's own site for a fact only that club holds.S12
datasetThe row links a third-party file. Reproducible by anyone; not a league publication. This is where every price lives.S12
internalThe row links only another page of this site. Fine for navigation, never presented as external evidence.S12
noneThe row has no link. This is the failure case, and the build fails on it.S12

The repository-wide audit in verify/source_audit.py applies the same test to every published row and the CI job fails on any row with no source link.

Generated by origin_lab/build.py from committed data. Every table row links the publisher it came from. A blank cell is a value no official publisher printed; it is never filled in. See Flagged for review.

A dash in a table cell means no source in this repository printed that value. It is never filled in, inferred or estimated. Values that need an owner's decision are on Flagged for review.
