A leaderboard with rewards pays for variance unless the eligibility rule is arithmetic. Nothing here allocates a payout, because no strategy clears the proper-score bar.

Append protocol. one JSON line per settled prospective bet: registration_id, game_id, kickoff_utc, recorded_utc, state (recorded or settled), price, model_prob, market_prob, outcome, pnl. A row may only be written before kickoff with state recorded; the same row is later updated to settled from the verified results feed. Rows written after kickoff do not count toward promotion, which is what keeps lookahead leakage out of the decision. Ledger file: escrow_ledger.jsonl

Commit that froze these rules: git log --oneline -- luck_lab/data/preregistration.json

Every figure on this page is a deterministic recomputation over files committed in this repository (market prices are tier dataset, not an official league source), or a value another session recorded against an official page, labelled as such.
