Validation gates

Validation gates

Nine gates stand between a backtest and a reward. This page shows the definitions, the results, the test suite and the protocol constants.

Passing is hard on purpose. A gate that cannot be evaluated is recorded as unverified, which is not a pass. The reward rule requires all nine.

Why G6 is the gate that kills most candidates

G6 compares the model's probability for every priced game against the de-vigged closing price using the Brier score. A model can be profitable only if it is better than the market at pricing, or at least not worse while selecting a biased subset. Every model here scored worse than the market, which is the honest reading: the market already contains the information these features carry. evaluation code ↗
