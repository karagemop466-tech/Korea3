The short version

The market wins. Our own line is genuinely independent — it explains the closing spread with a correlation of 0.800 — but it is 0.42 points worse per game on absolute error (p = 4.9e-24). An own line is a research instrument, not an edge by itself.
Not one strategy passed all eight gates. Four clear seven of them and fail only the multiplicity gate: in an 18-rule search, a 8.4% return over 607 bets is still consistent with luck. They are on watch — Wind 15+ mph: unders leads the board at a luck-adjusted 2.5%.
Parlays make it worse, not better. Across games the outcomes are independent (pooled φ = -0.024, p = 0.10), so a two-leg parlay compounds the vig instead of diversifying it. A leg pair must be correlated at φ ≥ 0.0975 to be worth the posted price. The only NFL pair that clears that bar is moneyline × spread on the same team (φ = 0.672) — and operators already re-price it.
