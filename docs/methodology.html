Method & Reproduction

How the pipeline works, how to rebuild it, and what it deliberately does not do.

Everything on this site is generated from committed code and pinned data. No figure is typed by hand.

Reproduce

git clone https://github.com/karagemop466-tech/Korea3.git
cd Korea3
python3 -m venv .venv && . .venv/bin/activate
pip install numpy pandas
python3 scripts/fetch_data.py      # re-download pinned data, verify SHA-256
python3 scripts/run_all.py         # features → model → bets → gates → JSON
python3 scripts/verify_external.py # external + integrity checks
python3 scripts/make_site.py       # rebuild this site from the JSON

Pipeline

  1. fetch_data.py — pulls the raw files from codeload at a pinned commit, records SHA-256.
  2. features.py — sequential Elo (margin-of-victory weighted, season mean-reversion) and point-in-time offensive/defensive form. Asserts no leakage by rebuilding ratings from truncated history.
  3. model.py — refits two OLS models each season on prior seasons only; σ from training residuals; produces our spread and total for every game, including unplayed ones.
  4. engine.py / strategies.py — mechanical rules → bets → settlement against observed prices.
  5. props.py — prop markets with prior-season empirical probability calibration.
  6. correlations.py — correlation estimates with bootstrap confidence intervals.
  7. validate.py — nine gates, zero-skill simulation, FDR, deflated Sharpe, monotonicity.
  8. leaderboard.py (inside run_all) — composite score, tiers, allocation weights.
  9. make_site.py — renders this site from docs/data/*.json.

Statistical notes

  • Staking — flat 1.00 unit per bet. Fractional Kelly is recorded per bet but is not the headline metric, because Kelly on an unproven edge simply scales the error.
  • Pushes — refunded (profit 0), never counted as losses. Integer prop lines are kept rather than nudged, because nudging them biases the over-rate downward.
  • Confidence intervals — percentile bootstrap over bets (6,000 draws) and a separate cluster bootstrap over seasons (4,000 draws), because bets inside a season are not independent.
  • Zero-skill null — outcomes redrawn at the de-vigged market probability of the side taken, 10,000 simulations per strategy.
  • Multiple testing — Benjamini–Hochberg at q = 0.10 across all non-control strategies.
  • Deflated Sharpe — per-bet Sharpe haircut for the number of strategies tried, using skew and kurtosis of the profit distribution (Bailey & López de Prado).
  • Seeds — every simulation uses a fixed seed; results are bit-reproducible.

Known limitations

  • Prices are unverified against an external source (IR-01).
  • Prop prices do not exist in the data; they are assumed (IR-03).
  • Weather (temperature/wind) is present in the source but deliberately unused, because a backtest would need the forecast available at bet time, not the realised value.
  • The model has no injury, roster, or market-movement information — all of which are likely to matter more than the features used here.
