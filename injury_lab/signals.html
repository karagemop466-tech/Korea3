The injury signal family: nine rules, nine gates, zero promotions

A pre-registered family of injury and depth signals, the gate register it must clear, and the pilot that shows the machinery works and the sample does not.

Nothing here is a finding about profitability. Six completed fixtures in the pinned dataset match a retained official capture, against a gate that requires 300 bets, 8 seasons and 40 holdout bets. The pilot columns exist to show the pipeline runs and to show how wide the noise is: the deliberately meaningless control rule “F05” wins five of six bets at the recorded closing prices. That is the argument for the gates, not against them.

Per-rule reasoning and the block that applies

F01 Charted first-string quarterback ruled out

cannot run before 2026 with the sources in hand: no archived depth chart has been retained for an earlier season, so the trigger is undefined for historical games. Forward-test only.

F02 Reported quarterback absence without a chart

this is the only injury rule that can be backtested historically today, because it needs no depth chart. It is also the rule the repository already tested without injuries (S8 'Backup-quarterback fade'), so a second claim on it inherits that family's multiplicity.

F03 Two or more charted first-string defenders out

needs the unit of every reported row. Today 23 of 139 captured rows have no unit because no captured page defines codes like DE, T and G - counted on the coverage page, and a gate this rule cannot pass until it is closed.

F04 Second string forced onto the field at cornerback

the joining rule for this one is unforgiving: report and chart disagree on player name form (Kevin Byard vs Kevin Byard III), so the join runs on the URL slug and needs an ID to be trustworthy at scale.

F05 Designation count as a proxy (deliberate negative control)

a negative control earns its place by being predicted to fail; if it 'works', the feature is measuring reporting behaviour, not football.

F06 Blank Game Status is not health (measurement control)

this is a gate, not a strategy: it exists so that a future run fails loudly if someone starts filling blanks with zero.

F07 Same-game spread + total double

this repository already measured the same-game spread x total dependence at phi = +0.0086 (95% CI -0.0162 to +0.0332) against a parlay that needs phi >= 0.0975 at -110 - see data/derived/corr_same_game.csv and corr_meta.json. A correlated-by-hand parlay does not become a priced edge by adding a second leg.

F08 Two-leg cross-game injury parlay

published as a documented way to lose vig twice, unless IG3-IG9 pass for both legs first.

F09 Player-prop combination off a depleted secondary

prop prices have no official publisher and are not in the pinned dataset this repository uses, so this rule is defined and cannot be settled here. Blocked by inputs, not by effort.
