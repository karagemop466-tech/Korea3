Reading rules used here

Published so they can be rejected. The clubs print no string numbers, no unit for a code, and no ordering inside a crowded cell.

  • string number = printed column index. None of the three pages labels a column. A parser that called column 2 “1st string” without saying so would be inventing a league convention.
  • unit = the section heading the row sits under. That is a published fact of the page, unlike a code → unit table assembled from what a reader assumes.
  • an ambiguous cell stays ambiguous. A cell with two names yields no first string here.
  • no de-duplication by player. A man listed in two slots is printed twice, because no page states the rule for counting him once (H14, H15).
