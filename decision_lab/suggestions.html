How to decide

The register is built so a decision can be recorded without editing any page. Each suggestion carries three fields that are empty until you fill them.

Why the gate is in code.

A convention that says "do not implement before deciding" is forgotten by the next session. check.py fails the build instead, so an undecided suggestion cannot quietly become an implemented one. This is the mechanism that makes the brief's "choose the best path before implementing any changes" enforceable rather than aspirational.

Generated by decision_lab/build.py from decision_lab/data/*.json. Standard library only, no network access, no manual input, deterministic output.

Provenance vocabulary used on every page: official league published by the NFL; official club published by an NFL member club; recomputed counted from rows already published here; derived grouped by a stated presentation convention; unverified blank, because no official source confirms it.

No page in this directory publishes a betting price, an odds line, a correlation coefficient, a return figure or a recommendation to bet. See flag D16.
