What the census means

Five different "number of games" figures are all correct. 7,548 = every row in the file (regular season + playoffs). 7,384 = rows with both scores. 7,075 = completed regular-season games, the sample the empirical pipeline models. 6,151 = completed regular-season games 1999–2022, the window its leakage test replays. 6,340 is the one figure this session could not reproduce from any filter (see F-07).
