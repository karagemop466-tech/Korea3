Correlation and dependence

Parlay and same-game pricing lives or dies on dependence. This page reports every dependence value that can be measured from the official-derived game data, with sample sizes and confidence intervals.

These are measured coefficients, not assumptions. Each value comes from the recorded outcomes of 4,853 priced games (2006–2025). Intervals are week-block bootstraps. Where a combination could not be measured, the cell is blank and listed on the review page.

How to use a phi value

For two binary legs with marginal probabilities pA and pB, the independent price uses pA·pB. The dependence-adjusted joint is P(A∩B) = pApB + phi·√(pA(1−pA)pB(1−pB)).

With pA = pB = 0.5 and phi = 0.67 (moneyline × spread), the joint is 0.50 instead of 0.25 — double the independent price. Multiplying marginals for that combination underprices the parlay by half. For legs in different games phi is 0.006, so the correction is negligible there.

phi is a linear dependence measure; it does not describe the tail of a multi-leg distribution. For three or more legs, use the measured joint rate in the table above or simulate the joint distribution.
