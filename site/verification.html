How row-level verification works

Every table on this site carries a source column, and every generated row is machine-checked to contain a link. There are three kinds of source cell:

  1. Pinned data link — points at the exact commit of the file the row came from, so a reader can open the file and find the record. Used for all game and market rows.
  2. Script link — points at the code that computed a derived number, together with the input dataset link. Used for analytic rows.
  3. Official source link — points at an NFL or licensed-operator page. Used for every rule, price convention and settlement claim.

Where a value could not be confirmed, the cell is blank and the row appears on Flagged for Review. No value on this site was inferred, interpolated or filled in from general knowledge.

What machine verification cannot do

An automated check can confirm that a link exists and resolves; it cannot confirm that a human-readable page still says what it said today. Two official pages were read in full during this session and are cited with the exact sentence they support (see Sources). Everything else that is cited to an operator or the league was verified by reading the page at the time of writing, and those readings are recorded in research/sources.md with the checking date.

Data-level checks (enforced in the pipeline)

  • Margin reconciles with the score on every row: margin = home_score − away_score.
  • Total reconciles with the score on every row: total = home_score + away_score.
  • Cover flag is consistent with the ATS margin on every row.
  • No unplayed game appears in any calculation.
  • Game identifiers are unique.
  • The dataset is pinned by commit and every file is checksummed (data/derived/checksums.txt).

NFL Line Lab — built for review, not for staking. Nothing on this site is betting advice. Market data is community-sourced (open dataset, pinned by commit); rules and settlement mechanics are cited to official NFL and licensed-operator sources. Every table states its source; anything unconfirmed is blank and listed on Flagged for Review.
