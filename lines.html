Line origination in practice: the model's own spread, total and win probabilities for unplayed games, compared with the market where a line exists.

Model output, not a pick. These are the lines this system would originate from its own ratings, shown next to the market line where one exists. The same system failed all nine validation gates, so treat the gaps as disagreement to investigate, not as value to bet.

Origin story: how a model line is built

  1. Elo ratings updated game by game in kickoff order, with a 75% carry-over across seasons and 55 Elo points of home field.
  2. Exponential moving averages (4-game half-life) of points scored and allowed for each team.
  3. A margin regression on Elo differential, rest differential and quarterback change, refit each season on all prior seasons.
  4. A totals regression on the four team scoring averages plus a roof indicator, refit the same way.
  5. Normal distributions around each fitted mean produce cover, over and moneyline probabilities.
