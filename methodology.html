Formulas

Elo update
  expected_home = 1 / (1 + 10^(-(elo_home + 55 - elo_away) / 400))
  multiplier    = ln(|margin| + 1) * 2.2 / (0.001 * winner_elo_diff + 2.2)
  elo_home'     = elo_home + 20 * multiplier * (won - expected_home)
  new season    : elo = 1500 + 0.75 * (elo - 1500)

Team scoring profile (half-life 4 games)
  off_t = off_(t-1) + (1 - 0.5^(1/4)) * (points_scored - off_(t-1))
  def_t = def_(t-1) + (1 - 0.5^(1/4)) * (points_allowed - def_(t-1))

Model
  margin ~ 1 + elo_diff + rest_diff + qb_change_home + qb_change_away      (OLS, prior seasons)
  total  ~ 1 + off_home + def_home + off_away + def_away + indoor           (OLS, prior seasons)
  P(home covers line L) = 1 - Phi((L - mu) / sigma)

De-vig (proportional)
  p_i = (1 / decimal_i) / sum_j (1 / decimal_j)

Bootstrap ROI interval
  resample weeks with replacement; ROI = sum(pnl) / n_bets

phi for two binary legs
  phi = corr(A, B);   P(A and B) = p_A p_B + phi * sqrt(p_A(1-p_A) p_B(1-p_B))

Limitations

  • Closing-price settlement is an upper bound; no intraday quotes are available.
  • The models use public, game-level information only: no tracking data, injuries, or player participation.
  • Elo, the moving-average half-life and the home-field constant are project choices, not estimates.
  • One season of opening lines exists, so closing-line value is unmeasurable at sample.
  • Brier skill is a proper scoring rule but says nothing about which side of a line to take; the gates use both.
  • Nothing here is a forecast of future results, and betting loses money for most participants.
