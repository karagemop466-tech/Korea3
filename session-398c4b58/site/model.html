Origination Model

Walk-forward Elo plus form and rest. Refit every season on prior seasons only, with an explicit point-in-time rebuild test.

The origination model is deliberately simple and deliberately leak-free: two linear models refit each season using only earlier seasons, on features that exist before kickoff.

margin ~ 1 + elo_diff + form_diff + rest_diff + div_game
total  ~ 1 + off_home + def_away + off_away + def_home + dome
