IR-04De-vig method biases the zero-skill null
The luck simulation de-vigs two-way markets proportionally, which is known to understate favourites' true probabilities (favourite–longshot bias). Consequence: p-values for moneyline strategies and for the always-favourite control are biased optimistic. The always-favourite benchmark shows p = 0.0156 for a +0.21% ROI — a false positive caused by this bias.		p-values for S11, S12, C02; the luck page narrativeneeds reviewsource
IR-05Opening-line file moves far more than expected
The 2021 opening-line file implies a mean open→close move of 3.40 points, roughly double what is normally reported. The file names a single book (WSGT) but carries no capture timestamp, so it is unclear whether these are true openers.
