Sources

Where every value on this site came from, and how each publisher is classified.

Tier definitions are this build's own, and they are recorded rather than assumed. The shared repository auditor at verify/source_audit.py keeps an OFFICIAL_HOSTS allow-list that does not include member-club domains, so club-published rows are classified there as dataset, not official. That shared allow-list was not edited by this session. Depth Lab records the club tier locally, here, so a reader can see the distinction and the open governance question is not silently closed.

How this build tiers a source

These are this build's own definitions, written down so a reader can argue with them.

official-league
Published by the National Football League on nfl.com. The league is the governing body and its injury report is the official availability document.
official-club
Published by a member club on that club's own domain. Officially operated by the club, but the clubs themselves label these charts unofficial, and most print no as-of date. Recorded at this tier so the distinction is visible rather than hidden.
