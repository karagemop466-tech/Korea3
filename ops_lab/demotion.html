Demotion gate: live → paper

The brief requires a “demotion gate that sends a live strategy back to paper”. Promotion to live is governed by nine gates; until now nothing governed the way back. The demotion gate below is symmetric with them: automatic, thresholded, and reversible only by re-passing the full promotion set — a single good week can never restore a demoted strategy.

Honest state: no strategy is live (0 of 11 pass the nine promotion gates), so the gate's live set is empty and nothing on this page is a statement about a live position. The trigger counts are an explicitly-labelled dry run on paper strategies — the same arithmetic that would run on a live book, exercised on history so the implementation is proven before it is needed.

Re-admission

how a demoted strategy returns

  • Re-admission requires re-passing all nine promotion gates on the updated window — the same bar as the first promotion: promotion gates ↗.
  • At least 100 new settled bets must accrue before re-evaluation; fewer cannot distinguish skill from luck at any realistic edge (the sample-size table shows even +2.6 pp needs ≈2,242 bets): NIST sample-size arithmetic ↗.
  • A demotion is recorded, never deleted; the record travels with the strategy.
  • Thresholds are owner-ratifiable: Q-ops3 in the questions register asks for that sign-off before any strategy is allowed to go live.
