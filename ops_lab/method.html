Method and limits

Definitions behind every number on these pages, written so each can be re-derived from the code it names. Where this lab mirrors a published convention (settlement, de-vig, bootstrap), the mirror is exact and stated; where it differs (per-strategy Brier), the difference is the point.

Definitions

each re-derivable from the linked code

Settlement convention
Score-derived outcome: 1 win, 0 push, −1 loss. Spread: home covers when (home−away) − spread_line > 0. Total: over when (home+away) − total_line > 0. Moneyline: higher score wins; a tie is a push. Mirrors line_lab/markets.py exactly.
Published-outcome mapping
closing_lines.csv publishes 1 win / 0 loss / 0.5 push; the feed maps that to 1 / −1 / 0 so both columns share one convention. The mapping is shown in stores.py, not hidden in a comment.
published_outcome_verified
The published outcome is re-derived from that closing row's OWN line (not the games.csv line) with the row's own side. 'MISMATCH' means one dataset row contradicts itself; such rows are listed on the flagged page and excluded from settlement claims.
Side normalisation
Sources publish spread and moneyline sides as team codes; the store normalises to home/away by comparing the code to games.csv home_team/away_team. The LAR→LA alias (FO5) is applied before comparison and disclosed.
Week-block bootstrap
Every CI resamples (season, week) blocks with replacement to the observed block count, 2,000 draws, seed 20261114 — the same convention the published leaderboard CI uses. Per-week aggregates make each draw O(weeks).
Brier skill, two definitions
Own-bets skill = 1 − Brier(model)/Brier(market) computed on the strategy's own scored bets (y = outcome > 0, pushes count as misses — mirroring the published code). The published per-strategy column is the market-universe value from the G6 test, identical within a market (FO2). Both are shown; they measure different things.
Fair moneyline
American price for win probability p: decimal 1/p; negative American −100·d/(d−1) when d < 2, positive 100·(d−1) otherwise. Pure arithmetic on the published model probability — no market input enters the origination.
De-vig
Proportional two-way de-vig (mirrors line_lab/markets.py), used only for the market probability difference on the own-book page.
Luck band (D5)
The strategy's per-week P&L sums are shuffled 2,000 times; the 95th percentile of the resulting max-drawdown distribution is the band. Exceeding it is the demotion trigger D5.
Trailing windows
D2/D3 evaluate every trailing-100-bet window (step 50) with at least 5 week-blocks; a trigger needs the statistic below 0 AND its one-sided 95% bound below 0.
Determinism
No clock enters the build (the checked-date constant is fixed per session); two runs produce byte-identical stores and pages, and the verifier enforces it.
Blank policy
A blank cell always carries a reason and is listed on the flagged page where it matters. A blank is never zero, never interpolated.

Limits

what this lab does not claim

  • No live strategy exists; every trigger count is a dry run on paper strategies.
  • No price, probability or ROI on these pages is new evidence of edge; the eleven strategies all fail the promotion gates and the split exists to show why more honestly.
  • Market numbers are tier-3 dataset values, never league-official; the store labels them so.
  • The feed cannot settle futures (win totals) or parlay legs from its rows; both gaps are published, not papered over.
