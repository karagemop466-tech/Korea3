Desk Ops — the operating model of the line desk

This lab implements the four operating pieces the brief asks for that no prior session had built: a price-snapshot store recording the opening and closing numbers for the markets this project originates and bets, a verified results feed so backtests and ROI have a settlement source at all, a leaderboard split that separates signal quality from staking outcome, and a demotion gate that would send a live strategy back to paper. It also documents the origination order — side first, then total, then moneyline — and closes the own-moneyline gap in the 2026 book with a recomputed fair price.

Standing rule

the rule every row on this site obeys

A value is published only if a hash-verified input states it or it is a labelled recomputation from those inputs. Everything else is blank and flagged — never zero, never inferred. The NFL publishes no machine-readable betting prices (see the data-rights review), so market numbers on this site come from the pinned open dataset and are labelled as such, not as official league publications.

Sources re-read 2026-11-14; pinned dataset commit a270278f3ac4 (hash-verified against data/provenance.json at build time). Analytical values on these pages are recomputed by ops_lab/ code from the committed, hash-verified inputs; no value is inferred. Unverifiable values are published as blanks and listed on the Flagged for Review page.
