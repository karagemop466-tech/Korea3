A02 — Different correlation samples reconcile; one publication label remains defective

The “Home cover x Over” row in the hub/pipeline CSV reports all-season n = 6,784, phi = +0.0086, 95% interval [−0.0162, +0.0332], and p = 0.4783. Independent calculation from the model dataset gives n = 6,784, phi = +0.008609 for all seasons, and n = 4,996, phi = +0.016283 for 2006–2025. The script uses nonmissing home_cover and over indicators (so pushes are excluded), but it does not require recorded odds for both legs or a non-tied moneyline result; see the dataset builder and correlation calculation. No confidence interval or p-value for the 2006–2025 recomputation is asserted here.

The separate root correlations page reports n = 4,853, phi = +0.016109. This is reproducible from line-lab features, line_lab/correlations.py, and its generated summary. Its same_game_dependence function requires nonmissing spread_line, total_line, home_spread_odds and over_odds, then removes ATS/total pushes and home-score ties to compute three leg pairs on one common sample. The two 2006–2025 inputs share the same 5,199 game IDs and matching scores, lines and relevant odds. Of the 4,996 settled cover/over pairs, 130 lack one or both required odds fields; 13 more are home-score ties removed by the line-lab's three-pair rule. Thus 4,996 − 130 − 13 = 4,853. The counts are different because the eligibility rules differ, not because either sample count failed to reproduce.

A separate reporting issue remains: the all-season n = 6,784 row in corr_same_game.csv is associated with prose describing 2006–2025. Existing flag X02 records that scope-label defect; this audit did not edit the underlying dashboard or data. The recomputation note records both the all-season and restricted scopes. The two-leg −110 arithmetic reference, phi = 0.0975, is checked in hub/check_decisions.py.

The NIST correlation reference defines the coefficient, while NIST's correlation-confidence-limits reference describes a Fisher-normal-approximation interval; neither validates this dataset. These are calculations on pinned third-party data, not official NFL statistics, sportsbook validation, or evidence of a betting signal.

A05 — Positive historical returns are not yet evidence of skill

The gate ledger contains 18 rows and every strategy has verdict=FAIL; four carry a PROVISIONAL tier but still fail the verdict. S14 (“Wind 15+ mph: unders”) illustrates the distinction: the local ledger reports n=607 and ROI=+8.41%, with nominal 95% interval [+0.75%, +16.07%] and p=0.0160, but adjusted q=0.2879 fails G4's q≤0.10 multiplicity requirement. Almost 30% of prices are imputed, and the wind field is marked unverified with no source field. These are retrospective calculations on a pinned non-official dataset, not an official NFL statistic or a verified edge.

The NIST multiple-comparison guidance explains why repeated comparisons need multiplicity-aware controls. A favorable in-sample estimate does not alone show prospective skill. The competition and rewards proposal retains unverified/unfunded awards; no funded prize or verified winner is claimed here.
