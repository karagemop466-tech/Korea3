What is different about this build

  • Every page is rendered from one generated summary.json; no number is typed by hand.
  • The pre-registered protocol, including the reward rule and the luck band, was committed before the first backtest.
  • The build check fails if a table row has no source link, if a blank lacks a link to the review page, or if a strategy's ROI in the pages disagrees with bets.csv.
  • Player props are declared blocked rather than estimated; the estimator and its required schema are committed.
