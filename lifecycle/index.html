What this build is. The bookkeeping layer the brief asked for: a price-snapshot store that records opening and closing numbers for every market, a verified results feed so backtests and ROI can be computed, a demotion gate that sends a live strategy back to paper, and a leaderboard that separates signal from staking. It defines the structures and, where a committed file exists, computes them. Every market price is blank and flagged, because no official publisher releases one.

Lifecycle defines the bookkeeping around a strategy: what price was recorded when a market opened and closed, what the settled result feed contains, the rule that retires a live strategy, and the separation of signal from staking. Every value is either an official-publisher fact, a value recomputed from a committed file and labelled as such, or a blank that is flagged for review.
