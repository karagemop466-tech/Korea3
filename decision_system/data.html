What is not obtained here, and why

The analysis sandbox can reach github.com, codeload.github.com and api.github.com, but GitHub serves release assets from release-assets.githubusercontent.com, which is not allowed. Rather than substitute an undocumented mirror, the fetcher is written to run in CI with the workflow token and to verify every SHA-256. Method shows the exact commands.
