Why this exists

An independent check is only independent if it does not reuse the code it is checking. decisions/recompute.py imports nothing from this repository and re-derives each number from the raw or committed CSV. Where a value could not be re-derived it says so rather than repeating the published figure.

The result

21 of 24 checks reproduced the published value exactly, including the 7,075-game universe, the MAE pair (10.670 vs 10.247), the same-game correlation, both parlay break-evens and the gate counts. No fabricated number was found.

Where it is soft

One entry is a labelling issue rather than an arithmetic one (D01: 10.670 is an MAE, not an RMSE). 2 entries are blocked because the underlying quantity does not exist in any official source — a statement about the world, not a bug.

Every check, with its formula

The formula column states the arithmetic in words so a reader can check it without running the script. The published-in column names the file and, where relevant, the line.

Retracted checks are kept, not deleted

While building this page the session raised three findings and withdrew them after checking its own arithmetic. They are recorded here rather than removed, because a verification log that hides its retractions is worth less than one that shows them.

Withdrawn claims
IDWhat was raisedWhy it was wrongWhere it is recorded
W01The '26.9% of prices imputed at -110' limitation is wrong because only 8.78% of bet rows are at -110.The published figure is games without a recorded price (1,902 of 7,075 = 26.88%), not bet rows at exactly -110. Recomputed correctly it matches.recompute.py
W02The re-derived same-game correlation is -0.0072, so the published +0.0086 cannot be reproduced.The draft rebuilt the cover indicator as (margin + spread_line > 0) and ignored the dataset's push convention. Using the dataset's own home_cover/over columns reproduces +0.0086 exactly.recompute.py
W03The 2-leg break-even of 0.0975 is algebraically wrong; the correct value is 0.20635.At p = 0.5 the denominator sqrt(p(1-p)p(1-p)) equals p(1-p) = 0.25, so both forms are identical. The draft had also used 2.1^3 = 9.261 for a 3-leg decimal when the correct per-leg decimal is 1 + 100/110 = 1.909, whose cube is 6.958.recompute.py
W04At least eight injury-report players across the four covered clubs appear on no depth row, so the other session's count of five undercounts.Four are verified missing (NE: Gilliam, Van Roten; WAS: Patrick; NYG: Harrison) plus DET: Joseph, i.e. five. The draft reached eight by including three New England defenders whose rows were never rendered because the fetched page truncated the defence table. Counting players that were never seen is exactly the inference this project forbids.recompute.py

None of the three was ever published as a repository defect. All three were caught by recomputing the published expression verbatim before publication.
