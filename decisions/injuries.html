The central finding: practice status is not availability

Of the 93 players who did not practise, 5 carry an official Out designation and 1 a Questionable one. The remaining 248 rows have no game status at all.

Why this changes how any injury signal must be built

Only 2.4% of the rows on the official page carry a final game status. A model that treats 'did not practise' as 'will not play' would invent absences the league has not declared. A model that ignores practice status throws away the only information actually present. The only defensible design has two separate fields and never merges them — proposal S11 on the suggestions page.

Structural gaps that limit any depth model

These are not defects to fix; they are the shape of the available evidence. Each caps what may honestly be claimed.

Structural gaps
IDGapOfficial source
G1No league-wide official depth chart. NFL.com /depth-charts and every /teams/<club>/depth-chart/ tested returned 404 on 2026-11-12; only club sites publish, and NE and DET label theirs unofficial in the page text.NFL depth charts (404) ↗ NE depth chart ↗ DET depth chart ↗
G2No official snap-count or participation page at nextgenstats.nfl.com/stats/participation (404). Replacement exposure therefore cannot be measured from an official source.NGS participation (404) ↗
G3The official injury page carries no date, timestamp or version. A snapshot is only as good as the hour it was taken; the page itself does not say when it changed.NFL injury report ↗
G4The official inactives page was empty when read ('Please check back soon'), so the last-instant availability list could not be captured for Week 10.NFL inactives ↗
G5The injury-report 'Injuries' column is mostly blank: only 6 of 254 rows named a body part, so injury type cannot be used as a feature even though the column exists.NFL injury report ↗
G6No official page quantifies how many points a starting player's absence is worth. Any such number in this project would be invented, so none is published.NFL injury report ↗
