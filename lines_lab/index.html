What this section is. It originates its own NFL side, total and moneyline numbers from a pinned dataset, then tries hard to disprove them. It is built so that a bad result is visible rather than hidden: a strategy that fails a gate is printed in the paper column with the gate that failed, and a value that has no source is printed blank. Nothing on these pages is a recommendation, a price you can bet, or a claim of edge.

The four things worth knowing before anything else

Each is a measured result on this site, not an opinion.

1. The model does not beat the market, and that is the headlinemeasured
The walk-forward fair line misses the actual margin by 10.651 points on average; the market misses by 10.212. The market is better in every one of the 22 test seasons. An origination model that loses every season is not a signal source; it is a baseline to improve on. See the table →
2. Not one of the 18 candidate rules survives multiplicity controlmeasured
All 18 were pre-registered and tested once. The best uncorrected p-value is 0.129; the Bonferroni threshold for 18 tests is 0.0028. Zero rules clear it. Publishing a "best rule" here would be publishing noise. See the table →
3. A lucky staking run cannot rescue a losing signal — and the board proves it livemeasured
Strategy S07 has the best staking return on the board (+8.87% per bet) and a signal lower bound of -2.88% — still below zero. Ranking on one number would have promoted it. See the table →
4. Opening prices barely exist, so closing-line value cannot be measuredmeasured
Opening numbers exist for 272 of 7,412 games (3.67%), all in 2021, from one book, with no price column at all. Closing-line value needs a timestamped price on both sides of the move. It cannot be computed from this data, and the site does not compute it. See the table →
