Nothing on this page has been implemented. The page exists so a path can be read, compared and chosen before any change is made. A suggestion is a proposal with a problem attached, the questions that must be answered first, and the cost of getting it wrong. The recommendation at the bottom is a recommendation, not a decision — the decision is yours.

How to use this page

  1. Answer or accept a blocking question on the questions page. A proposal whose blocker is open cannot be judged solved.
  2. Choose one path, not a pile of items. Later steps in a path depend on earlier answers.
  3. Implement one suggestion, then re-run the build and the checks. The build is fail-closed.
  4. Record the choice with a date and an owner. Nothing is marked done without evidence.

Recommended order, and why

B, then C, then A. B is first because it needs nothing that is not already reachable: the club pages and the official injury report exist and can be verified, so league-wide availability is an engineering problem rather than a commercial one. C is second because it is cheap and it stops the site overclaiming while B is being built. A is last and is the only path to a real betting edge, but it cannot start without a vendor, so recommending it first would be recommending a wait.

Do not start SG11 (fund or drop the competition) before Q01 and Q11 are settled. Funding a prize on data that may not be lawfully held, or on a board with nothing live, would be the one mistake on this page that costs money.

What choosing a path does and does not authorise

Does authorise: work on the sequence in the chosen path, using data already lawfully held, with every change re-verified by the build.

Does not authorise: acquiring or scraping data the NFL terms prohibit, publishing a market number without a source, or funding a prize. Those stay blocked on Q01 and Q04 whatever path is chosen.
