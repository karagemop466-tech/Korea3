Why the two columns are not added together. Picking winners and choosing stake size are different skills and they fail differently. A board that ranks one number lets a good staking run hide a bad signal, and lets a bad stake plan sink a good one. So the board publishes them side by side and never sums them into a rank. This page's own data shows why: strategy S07 has the highest staking return on the board (+8.87% per bet) and a signal lower bound that is still -2.88%. A one-column board would have ranked it first. The two-column board shows a lucky run sitting on top of a negative edge.

The same bets, sized two different ways. If the signal were real, both plans would agree on its direction. Only the magnitude should move.

Both plans place the same bets on the same games; only the stake differs. A sign flip between the two would mean the return is a sizing artefact, not an edge.
